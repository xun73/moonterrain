# 月球觀測儀（Moon Terrain）

單一 HTML 檔的互動式月球觀測工具，可在電腦瀏覽器、平板、手機上直接使用。
以 Three.js 即時渲染立體月面，顯示真實的月球觀測資料，並支援地形特徵查詢與照片疊圖。

## 立即使用

GitHub Pages 開啟：

https://xun73.github.io/moonterrain/

無需安裝任何軟體，開啟網頁即為目前的真實月相。
（`moonterrain.html` 為正式來源檔，`index.html` 是 Pages 使用的同內容副本。）

## 功能

- **真實觀測資料**（三體力學模型，誤差 < 0.1°）
  - 月齡、被照明率、視直徑、月地距離、下次新月
  - 緯度/經度天平動、位置角 P、視差角 q
  - 月出 / 月沒時間
- **顯示設定**
  - 地形名稱標籤（亮面/暗面）、地形外框、經緯網格
  - 地形詳細程度、地形起伏（LOLA 高程位移）
  - 月球視野旋轉、翻轉、自由旋轉（中心標記經緯度讀數）
  - 顯示方向：地平天頂向上 / 天球北極向上 / 月球北極向上
  - 觀測者位置視差修正、整顆月球變亮
- **地形特徵查詢**：內建隕石坑、月海、山脈等大型資料庫，點選即顯示資訊並定位
- **照片疊圖**：上傳照片疊在月面上並調整大小、旋轉、透明度，可下載目前畫面
- **響應式版面**：桌面雙欄、平板/手機自動縮小欄位（面板欄位高度統一）

## 資料與圖片來源

- 月面紋理：NASA LROC / LOLA、Solar System Scope 8K 月面
- 月球曆算：改良的三體天文演算法（曆書精度）
- 地形特徵名稱：國際天文聯合會（IAU）命名

## 技術

- 單一 `index.html`（約 1.9 MB），無建置步驟
- [Three.js](https://threejs.org/) r128、[Tailwind CSS](https://tailwindcss.com/)、[Font Awesome](https://fontawesome.com/)
- 全程使用 HTTPS CDN，經 GitHub Pages 免費託管
- 沒有本機紋理檔時自動改用網路紋理，離線時退回程式化材質
